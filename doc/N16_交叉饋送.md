# N16 交叉饋送

`dsp/include/daphne/dsp/crossfeed.h`、`dsp/src/crossfeed.cpp`

耳機用：每一側都混入另一側經一階低通後的訊號。

```
L' = (1 − k)·L + k·lp(R)
R' = (1 − k)·R + k·lp(L)
lp:  y += (x − y)·a,  a = dt / (RC + dt),  RC = 1 / (2π·fc)
```

- 偏向一側的聲音，低頻也會傳到另一耳；置中的聲音（L = R）在 fc 以下維持原位準（k + (1 − k) = 1）。
- 參數：`amount` k ∈ [0, 1]、`fc` ∈ [100, 3000] Hz；NaN 輸入時用安全預設值（k = 0、fc = 700）。
- 只處理立體聲，其他聲道數直接通過（`is_identity`）。
- 位置：增益級之後、EQ 之前，原取樣率。
- `set_params` 可從任何執行緒呼叫（原子變數），播放執行緒不會被鎖。
