# N16 交叉饋送

`dsp/include/daphne/dsp/crossfeed.h`、`dsp/src/crossfeed.cpp`

耳機用：每一側都混入另一側經一階低通後的訊號。

```
L' = (1 − k)·L + k·lp(R)
R' = (1 − k)·R + k·lp(L)
lp:  y += (x − y)·a,  a = dt / (RC + dt),  RC = 1 / (2π·fc)
```

- 偏向一側的聲音，低頻也會傳到另一耳；置中的聲音（L = R）在 fc 以下維持原位準（k + (1 − k) = 1）。
- 參數：`amount` k ∈ [0, 1]、`fc` ∈ [100, 3000] Hz；NaN 輸入時用安全預設值（k = 0、fc = 700）。
- 只處理立體聲，其他聲道數直接通過（`is_identity`）。
- 位置：增益級之後、EQ 之前，原取樣率。
- `set_params` 可從任何（一個）控制執行緒呼叫，三個值經 mailbox 一起交給播放執行緒（與 EQ 相同），播放執行緒不會被鎖，也不會讀到新舊混合的參數。
- **漸變**：`prepare()` / `reset()` 後第一個區塊直接用最新參數；之後開關、`amount`、`fc` 的改變讓 k 與低通係數 a 在 20 ms 內線性移到目標（與增益級相同，與區塊大小無關，最後剛好落在目標）。關閉就是 k 漸變到 0；漸變結束後直接複製輸入（逐位元 identity），低通狀態歸零，下次開啟從靜止開始。
