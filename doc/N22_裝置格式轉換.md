# N22 裝置格式轉換

`core/include/daphne/engine/sample_format.h`、`core/src/sample_format.cpp`

float64 樣本轉成裝置的位元組格式（小端；ASIO 大端格式由輸出端交換位元組）。

## 格式

| `SampleType` | 說明 |
|---|---|
| `Int16` | 16 bit |
| `Int24In32` | 24 bit 左對齊在 32-bit 容器（WASAPI 常見） |
| `Packed24` | 3 位元組 24 bit |
| `Int32` | 32 bit |
| `Int32Low` | `valid_bits`（16–24）右對齊在 32-bit 容器（ASIO Int32LSB16..24） |
| `Float32` / `Float64` | 浮點 |
| `Dsd8Msb` / `Dsd8Lsb` | ASIO 原生 DSD：每位元組 8 個 DSD bit，最早的 bit 在 MSB / LSB；每聲道每 frame 一個位元組（由 N20 產生，不經過這裡） |

`effective_bits()`：整數格式為有效位元，float32 算 24（尾數），float64 算 53，DSD 為 1。

## 整數轉換

```
v = nearbyint(x · 2^(N−1))     （round half to even）
v 夾在 [−2^(N−1), 2^(N−1) − 1]
```

- 縮放用 2^(N−1)（不是 2^(N−1) − 1）：解碼器以 sample / 2^31 正規化，所以 N bit 的來源送進 N bit（或更寬）的容器時逐位元還原。
- 這裡不加抖動：抖動在量化級（N21）決定，量化級之後的樣本已經在格點上，這裡只是換表示法。
- 超出範圍會被夾住並計入回傳值。

## NaN

任何格式的 NaN 都換成 0 並計入回傳值。上游出現 NaN（發散的濾波器、壞掉的解碼器）時輸出靜音，不會送出未定義的值。浮點格式超過滿刻度的值保留不動。

## 驗證（`tests/test_output_format.cpp`）

| 測試 | 結果 |
|---|---|
| 16-bit 樣本（含 ±滿刻度、±1）→ Int16：逐值相同；→ Int24In32 / Int32：左移 16 位、逐值相同；無削波 | 通過 |
| Packed24 的位元組排列（−2^23、2^23 − 1、0x1234） | 通過 |
| Int32Low 20 bit：0.5 → 2^18、−1 → −2^19 | 通過 |
| 1.5 / −1.5 → 32767 / −32768；0.5 LSB → 0、1.5 LSB → 2（round half to even）；NaN → 0；計數 3 | 通過 |
| float32 / float64：1.5、−1.5 原樣保留；NaN → 0、計數 1 | 通過 |
