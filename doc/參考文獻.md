# 參考文獻

Daphne 各級設計所依據的標準、論文、教科書與官方文件，依 N0–N24 的章節排列。每一筆都寫出它對應到哪個設計決定；沒有出處、屬於本專案自己決定的部分，在各節最後的「本專案自訂」列出，避免讓人誤以為有外部依據。

編號格式：`[類別-序號]`，在其他文件中以此引用（例如「TPDF 抖動 [Q-1]」）。
