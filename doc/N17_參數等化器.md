# N17 參數等化器

`dsp/include/daphne/dsp/eq.h`、`dsp/src/eq.cpp`、`dsp/include/daphne/dsp/mailbox.h`、`core/src/stages.cpp`

EQ 在原取樣率執行（增益與交叉饋送之後、升頻之前），所以設計取樣率就是來源取樣率，PCM 與 DSD 兩種核心的 EQ 完全相同。

## 頻帶設計

f 限制在 [10 Hz, 0.495 fs]。

| 類型 | 設計 |
|---|---|
| `PK` 峰值 | 0.2 fs 以下用 RBJ。0.2 fs 以上雙線性轉換會擠壓鐘形，改用同一個類比原型的 matched 設計（Vicanek 2016）：極點對應類比原型，零點擬合 DC 與 f0 的類比振幅且 f0 斜率為 0，在 0.2 fs 處與 RBJ 連續。\|gain\| < 1e-4 dB 為直通段。Q ∈ [0.05, 40] |
| `LS` / `HS` 低 / 高架 | RBJ 架式，q 為斜率 S ∈ [0.1, 10] |
| `HP` / `LP` | RBJ 12 dB/oct，Q ∈ [0.1, 10] |
| `HP24` / `LP24` | 兩段 Q 0.7071 的 RBJ（Linkwitz-Riley，f 處 −6 dB） |
| `NOTCH` / `AP` / `BP` | RBJ，Q ∈ [0.1, 30]；帶通峰值 0 dB |

- cascade 只包含使用者啟用的頻帶。
- 參數為 NaN 時不會被夾成邊界值，而是讓該段的非有限值保護把它靜音。

## 自動前級

自動前級 ≤ 0 dB，由三項相加（取負值）：

- cascade 振幅的峰值：取樣點為 20 Hz – 20 kHz 對數 501 點，再加上各頻帶頻率。
- 步階過衝估計：Q > 0.7071 的提升型峰值 / 架式頻帶，阻尼 z = 1/(2Q)，`20·log10(((A − 1)(e^(−πz/√(1−z²)) + 1) + 1) / A)`。
- 0.2 dB 餘量。

手動前級只能更低：`min(manual, auto)`。

## 處理

```
out = cascade(x · preamp)   （每個聲道）
```

- **參數交接**：`set_params()` 可以隨時從控制執行緒呼叫，交接透過 `Mailbox`，不會鎖住播放執行緒：
  - 控制端 `post()` 新物件，較新的會取代還沒被取走的。
  - 播放端 `take()` 取最新的。
  - 被換下的物件交回控制端，在下一次 `post()` 或解構時釋放。播放執行緒從不釋放記憶體。
  - 交回的位置（retired）只有一格：只有播放端會填它（看到它是空的、而且在取走新物件之前），控制端只在發布之後清空它。所以 `post()` 返回後，播放端不是已經拿到這個物件，就是格子已空、下一次 `take()` 一定拿到。格子還沒被清空時，`take()` 把新物件留到下一次。
  - 以前格子滿的時候播放端會自己 `delete`（罕見的交錯時序），與「從不釋放」不符；`tests/test_realtime.cpp` 以兩個執行緒 20 × 20000 次 post 檢查：播放執行緒從未釋放物件，控制端停止後最多兩次 `take()` 就拿到最後一個。
- **滑動**：段數不變時，每 15 ms 讓每個係數與前級往目標移動剩餘距離的 0.28，差距 < 1e-5 時直接到位。
- **交叉淡化**：段數改變或開 / 關時，舊設定與新設定從同一個輸入各自計算，以 50 ms 升餘弦交叉淡化，不會爆音。
- **reset**（換軌、搜尋）：直接跳到最新參數並清除狀態。
- **非有限保護**：一段的狀態變成非有限或達到 1e9（不穩定或溢位）時清除該段，該區塊輸出靜音。
- **效能**：cascade 以「一段接一段處理整個區塊」執行，每段的遞迴狀態留在暫存器裡，每個聲道一條獨立的遞迴（Direct Form I）。

速度（60 秒立體聲 44.1 kHz、4096 frames 區塊）：

| 頻帶數 | 時間 | 即時倍數 | 重構前 |
|---|---|---|---|
| 1 | 0.013 s | 4700× | 0.036 s |
| 5 | 0.060 s | 990× | 0.172 s |
| 10 | 0.118 s | 510× | 0.344 s |
| 20 | 0.236 s | 250× | 0.726 s |

約快 3 倍。

### 已知限制

係數滑動是直接內插 Direct Form I 係數。轉角接近 Nyquist 的頻帶（例如 48 kHz 下 20 kHz 的低架，極點在 −0.65）滑動時會有短暫的暫態；一般頻帶（100 Hz 低架、1 kHz 峰值）滑動時的樣本變化不超過訊號本身的斜率。
