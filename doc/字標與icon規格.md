# 字標與 icon 規格

Daphne 的字標（Δάφνη、DAPHNE）、花瓣（重音 tonos）與 icon 的完整規格。實作在 `src/Daphne.Extension/web/daphne.js`（元件）與 `daphne.css`（尺寸、位置、顏色）。

**唯一標準：** 所有花瓣都以 icon 中 α 上的花瓣為準。花瓣的形狀與角度只有一個來源（`daphne.js` 的 `TONOS_D`），所有地方都由同一組元件產生，不另外畫。

---

## 1. 字型

| 用途 | 字型 | 來源 |
|---|---|---|
| Δάφνη（含 icon 的 α） | **GFS Didot** Regular | 內附 `web/fonts/GFSDidot-Regular.ttf`（原檔，未修改，191 KB），授權 SIL Open Font License 1.1（`web/fonts/OFL.txt`） |
| DAPHNE | **Georgia** Regular | 系統字型（後備 `"Times New Roman", serif`） |

- GFS Didot 以原檔內附：子集化屬於 OFL 的修改版本，修改版不能沿用保留字型名稱，所以不做子集。
- 確認方式：把 icon 的 α 與各字型的 α 等高疊合比對，GFS Didot 吻合度 **0.993**（IoU），寬高比與 icon 相同（1.165）；Georgia 0.466。

### GFS Didot 的度量（unitsPerEm 1000）

| 項目 | 值 |
|---|---|
| hhea ascent / descent | 947 / −277（與 OS/2 winAscent / winDescent 相同，fsSelection 未設 USE_TYPO_METRICS） |
| line-height: 1 時基線位置 | 行框頂端往下 **0.835em**（半行距 (1 − 1.224) / 2 = −0.112，加上 ascent 0.947） |
| 行內元素內容框頂端 | 基線上方 **0.947em** |

| 字元 | 字寬 | 墨跡範圍（x、y，y 向上） |
|---|---|---|
| Δ U+0394 | 615 | x 32–587，y 0–707 |
| α U+03B1 | 627 | x 47–606，y −11–469 |
| φ U+03C6 | 665 | x 34–633，y −233–484 |
| ν U+03BD | 465 | x 18–434，y −25–479 |
| η U+03B7 | 529 | x 35–498，y −238–464 |

字型有 GPOS kern，所以 α 一律保留為文字（花瓣疊在上面），不換成圖片，讓字型自己處理字距。

## 2. 花瓣（tonos）

### 2.1 來源與量測

- 量測原圖：icon 的 2048 × 2048 @2x PNG（即 1024 icon 的兩倍）。設計原稿不在 repo 內（`icon/` 已列入 `.gitignore`）。
- 方法：每個像素解成「底色 + α 色 + 花瓣色」的混合比例（底 `#2C1C3E`、α `#FDF4F7`、花瓣 `#E48DB4`），取 50% 覆蓋的邊緣，描出輪廓後簡化（誤差 < 0.6 px @2048），共 34 點。
- icon 中 α 的字級：α 墨跡寬 939.1 px、高 806.5 px @2048，對應 GFS Didot α 的 559 × 480 單位，即 **1.680 px / 單位**，等於 1024 icon 上 **840.0 px** 的字級。

### 2.2 形狀

兩端尖、中段偏下最寬的葉形，**順時針 26.1°**（長軸相對垂直線；角度已畫進輪廓，不另外旋轉）。以 GFS Didot 單位描述，原點 = α 的字形原點、y = 0 為基線、y 向下：

### 2.3 在 α 上的位置（em，以 α 的字級為 1em）

| 項目 | 值 |
|---|---|
| 外框寬 × 高 | **0.1219em × 0.2258em** |
| 外框左緣 | α 字形原點往右 **0.2535em** |
| 外框上緣 | 基線上方 **0.769em**；CSS 為行內框頂端往下 **0.178em**（0.947 − 0.769） |
| 花瓣中心 | 字形原點往右 0.315em、基線上方 0.656em |
| 相對 α 墨跡 | 外框左緣距 α 墨跡左緣 0.2066em；外框上緣在 α 墨跡上緣上方 0.3007em |

## 3. 元件

| 元件 | 結構 | 說明 |
|---|---|---|
| `alpha()` | `<span class="dp-alpha">α<svg class="dp-tonos">花瓣</svg></span>` | α 加花瓣。`.dp-alpha { position: relative }`；`.dp-tonos { position: absolute; left: .2535em; top: .178em; width: .1219em; height: .2258em }` |
| `greek()` | `<span class="dp-greek">Δ` + `alpha()` + `φνη</span>` | Δάφνη。`aria-label="Δάφνη"` |
| `icon()` | `<span class="dp-icon"><span class="dp-icon-a">` + `alpha()` + `</span></span>` | icon |
| `PETAL` | 同一個花瓣 SVG（viewBox 同上） | DAPHNE 前面的花瓣（`.dp-petal-svg`） |
| `mark()` | `<span class="dp-mark">` + 花瓣 + `DAPHNE</span>` | 訊號路徑卡片用的 DAPHNE 字標 |

## 4. Δάφνη

| 項目 | 規格（所有地方相同） |
|---|---|
| 字型 | GFS Didot，font-weight 400 |
| 字距 | `letter-spacing: 0`（字型原本的字寬；實測各字母位置與字型預期相差 < 0.01em） |
| 行高 | 1 |
| 顏色 | 淺色主題 `#2B1B3D`，深色主題 `#FFF6FA`（`--dp-ink`） |
| 重音 | 花瓣（`alpha()`），不用字型本身的 ά 重音 |

| 位置 | 字級 | 基線 | 字形原點 |
|---|---|---|---|
| 關於頁（`.dp-wordmark`，105 × 38 px 框） | 36.62px | 框頂往下 28.77px | 框左 −0.60px |
| 設定頁標題（`.dp-title`，56px 高） | 38.32px | 框頂往下 32.10px | 框左 0.82px |

這兩組數值取自原本字標圖片中 Δ 的位置與高度（Δ 高 0.707em），換成文字後與原圖疊合，字母位置一致。

## 5. DAPHNE

| 項目 | 規格 |
|---|---|
| 字型 | Georgia Regular |
| 字距 | **0.32em**（尾端以 `margin-right: −0.32em` 抵消，置中時不偏） |
| 行高 | 1 |
| 花瓣 | 同一個花瓣（形狀與 26.1° 同 icon），**高 0.692em**（Georgia 大寫高度）、**寬 0.374em**（花瓣本身的寬高比） |
| 花瓣與 DAPHNE 間距 | 0.43em |

花瓣高度對齊大寫字母高度，沒有照 icon 的比例縮小：照 icon 比例（花瓣高約為 α 高的 0.47 倍）在 12px 的大寫旁只有約 4px。

| 位置 | 字級 | 字距換算 | 花瓣 | 顏色 |
|---|---|---|---|---|
| 設定頁標題（Δάφνη 下方） | 12px | 3.84px | 4.5 × 8.3px | 主題次要文字色 `--text-3` |
| 關於頁（Δάφνη 下方那行） | 12px | 3.84px | 4.5 × 8.3px | 主題次要文字色 `--text-3` |
| 訊號路徑卡片：解碼 | 14px | 4.48px | 5.2 × 9.7px | 該行文字色 85%（`color-mix(in srgb, currentColor 85%, transparent)`） |
| 訊號路徑卡片：DSP 標題後 | 14px | 4.48px | 5.2 × 9.7px | 卡片列文字色 85%（卡片顯示後讀取列文字的實際顏色） |

- 設定頁標題的 DAPHNE 置中在 Δάφνη 正下方（原圖 x 247 = 56.2px），top 42px。
- 訊號路徑「解碼」：「解碼」13px `#8A8FA8`，與字標間距 10px，垂直置中。
- DSP 標題：DSP 後間距 10px（標題本身 8px + 2px）。

## 6. icon

| 項目 | 規格 |
|---|---|
| 尺寸 | `--s`（關於頁 66px），圓角 24%，外框 `0 0 0 1px rgba(ink, .10)` |
| 底色 / α 色 | 淺色主題：底 `#2C1C3E`、α `#FDF4F7`；深色主題：底 `#FDF4F7`、α `#2C1C3E` |
| α 字級 | **0.8203 × 邊長**（840 / 1024） |
| α 字形原點 | 左緣往右 **0.2426 × 邊長** |
| α 基線 | 頂端往下 **0.8311 × 邊長**；CSS 為 `.dp-icon-a` top **0.1461 × 邊長**（0.8311 − 0.835 × 0.8203） |
| 花瓣 | `alpha()` 的花瓣，與其他地方同一個 |

與原 icon 圖片疊合比對，只剩 α 與花瓣邊緣的反鋸齒差異。Windows 執行檔與工作列的 icon 屬於主程式，不在此範圍。

## 7. 主題

深色主題：night、wood、glass、neon；其餘（miku、flat、washi、vinyl）為淺色。

| 變數 | 淺色主題 | 深色主題 |
|---|---|---|
| `--dp-ink`（Δάφνη） | `#2B1B3D` | `#FFF6FA` |
| `--dp-tile`（icon 底） | `#2C1C3E` | `#FDF4F7` |
| `--dp-tile-ink`（icon α） | `#FDF4F7` | `#2C1C3E` |
| `--dp-title`（設定標題的分隔線與「再生設置」） | `img/title-dark.png` | `img/title-light.png` |

花瓣固定 `#E58FB7`，不隨主題改變。
