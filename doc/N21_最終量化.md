# N21 最終量化

`dsp/include/daphne/dsp/quantizer.h`、`dsp/src/quantizer.cpp`

處理鏈最後一級（PCM 核心、整數裝置格式）：

```
q = round((x + d) · 2^(N−1)) / 2^(N−1)，夾在 [−1, 1 − 1 LSB]
d = (u1 − u2) · LSB      u1, u2 ∈ [0, 1) 均勻分布 → 三角分布 ±1 LSB（TPDF）
```

- **字長**：裝置字長（16 / 24 / 32）；放在所有位準變化之後，抖動永遠對應實際的輸出格點。
  - 處理鏈之後還有的位準變化（兩條鏈的 50 ms 交叉淡化、搜尋或重開後的淡入、重開前的淡出、暫停的 20 ms 淡出淡入）在整數裝置上同樣以 TPDF 抖動重新量化：播放器的淡化用另一個量化器（N4），暫停的淡化在送料端（N23）。增益為 0 或 1 的樣本不動，淡出終點保持數位靜音。
- **為什麼一律用 TPDF**：
  - 16 bit 以下單純捨入會把小訊號變成諧波失真；TPDF 讓誤差變成穩定、與訊號無關的噪聲。
  - 高通 TPDF 與 TPDF 聽感上沒有差別。
  - 24 bit 以上的抖動位準在 −144 dBFS 以下，影響可忽略，但規則一致。
- **不做噪聲整形**。
- **亂數**：xoshiro256**，以 splitmix64 從固定種子初始化；`reset()` 回到同一序列，同一段輸入每次都得到相同輸出。兩個均勻值的取用順序寫成明確的兩個陳述，不依賴編譯器的求值順序。
- **削波計數**：`clip_count()`。量化後的值已經在裝置範圍內，N22 的轉換看不到這些削波，所以處理鏈以 `DspChain::take_clips()` 取出增量，播放器加進回報的 `clipped`（C API `dc_state`、命令列 `render-dsp` 同）。升頻後的樣本間峰值（N6 不截斷）就是在這裡被夾住，`clipped` 不為 0 表示需要降低音量或 headroom。

## 什麼時候省略（bit-perfect）

以下條件都成立時，處理鏈不放量化級，樣本直接交給 N22 的整數轉換，逐位元不變：

- 濾波器是單位脈衝（原取樣率、沒有 apodize）
- 增益 0 dB（音量固定或 0 dB，且 headroom 0）
- 交叉饋送與 EQ 關閉
- 不是 DSD 轉 PCM（那有 +6 dB 與限幅）
- 來源是整數 PCM，且位元深度 ≤ 裝置的有效位元
- 裝置是整數格式（浮點裝置不需要量化）

組裝與實機 bit-perfect 驗證在 N4 / N24。

## 驗證

### 與重構前的實作比較

16 / 24 / 32 bit，200 個區塊、每區塊 4096 個立體聲 frames，1.05 振幅正弦（含削波）：輸出**逐樣本相同**，削波數相同。

### 單元測試（`tests/test_output_format.cpp`）

| 測試 | 結果 |
|---|---|
| 16 bit、−90 dBFS 1 kHz：每個輸出都在 16-bit 格點上 | 通過 |
| 誤差平均 < 0.01 LSB；誤差變異數 = 0.25 LSB²（± 3%）＝ TPDF 的 LSB²/6 + 捨入的 LSB²/12 | 通過 |
| 三次諧波與基頻差 > 30 dB，且不高於噪聲底 4 倍（沒有捨入失真） | 通過 |
| 1.2 / −1.2：削波計數 2，輸出 32767/32768 與 −1 | 通過 |
| 處理鏈（`tests/test_chain.cpp`）：16-bit fs/4、45° 正弦（樣本在滿刻度、波形峰值 √2）升頻 2 倍到 24-bit：`take_clips()` 計到量化級夾住的樣本，取出後歸零；沒有量化級時為 0 | 通過 |
