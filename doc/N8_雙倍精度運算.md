# N8 雙倍精度運算（double-double）

`dsp/src/dd.h`、`dd.cpp`、`dd_ops.h`、`dd_conv.h`、`dd_conv.cpp`、`dd_conv_avx2.cpp`

濾波器設計與高精度卷積用的 double-double 運算：一個值是 `hi + lo` 的未求值和（|lo| ≤ ulp(hi)/2），有效位數約 106 bit，相對精度約 1e-32。

## 基本運算（`dd.h`）

| 運算 | 做法 |
|---|---|
| `+` | IEEE 精確的 two-sum（hi、lo 各自 two-sum 後重新正規化） |
| `*` | `p = a.hi·b.hi`，`e = fma(b.hi, a.hi, −p)`（精確誤差），`t = fma(a.lo, b.hi, a.hi·b.lo)`，`e = (t + e) + a.lo·b.lo`，quick two-sum |
| `div(a, b)` | 兩項除法：`q1 = a.hi / b.hi`，`r = a − b·q1`，`q2 = r.hi / b.hi` |
| `sqrt` | 雙精度開根號 + 一次牛頓修正 |

乘法在最後幾個 bit 不可交換（`a.lo·b.hi` 經過 FMA，`a.hi·b.lo` 先捨入）。`dd_ops.h` 以樣板對純量與 AVX2 向量重複同一個運算順序，因此兩條路徑結果逐位元相同。

常數：`kPi`、`kTwoPi`、`kInvTwoPi`、`kLn2`，lo 部分皆為正確值。

## 函數

| 函數 | 用途 | 做法 |
|---|---|---|
| `sincos_series` | FFT 旋轉因子 | `k = round(a / 2π)`，`r = a − k·2π`（\|r\| ≤ π），泰勒級數直到項 < 1e-33（最多到 r^81） |
| `sincos` | 逐頻點迴圈 | 2π 化簡後再以象限化簡到 \|t\| ≤ π/4，級數只需約 20 項 |
| `exp` | 逐頻點迴圈 | `r = (a − m·ln2) / 2^10`，expm1(r) 用 10 項級數，再做 10 次倍角 `s = s(s + 2)`，最後 `(1 + s)·2^m` |
| `log` | 逐頻點迴圈 | 雙精度 log 起始，一次牛頓步 `y + a·exp(−y) − 1`（每步正確位數加倍，一步就從 double 到 double-double） |
| `sinc` | 原型濾波器 | `sin(πx)/(πx)`，\|x\| < 1e-15 時為 1 |

旋轉因子刻意使用 `sincos_series`：同一張大小 n 的表供所有級數與所有 FFT 共用，結果與大小無關且逐位元穩定；它只計算 n/2 次，成本可忽略。

## FFT 與卷積核心（`dd_conv.*`）

- 複數陣列存成四個平面（re.hi、re.lo、im.hi、im.lo），AVX2 + FMA3 一次處理 4 個值。
- `butterflies`：一個 radix-2 級的一段蝶形；`butterflies2`：兩個相鄰級融合，每個單元讀 4 點、做兩級蝶形、寫回一次，記憶體掃描次數減半，結果與逐級計算逐位元相同。
- `mac`：`acc += x · h`（複數），供高精度卷積使用。
- `Fft`：執行期卷積用的 double-double FFT，每級的旋轉因子連續存放。
- CPU 偵測（cpuid）：有 AVX2 + FMA3 才用向量路徑；環境變數 `DAPHNE_DD_SCALAR=1` 強制純量路徑（用於比對與量測）。
- `dd_conv_avx2.cpp` 單獨以 `/arch:AVX2` 編譯，其餘程式維持基本指令集。

## 驗證

| 項目 | 結果 |
|---|---|
| AVX2 路徑 vs 純量路徑（8192 taps ×4、phase 0.5 的完整設計，hi 與 lo） | 逐位元相同 |
| 與重構前的實作比較（96 組設計，見 N7） | hi、lo 全部逐位元相同 |
| 設計結果的 DC 增益（hi + lo 以補償加總） | 與 1 的差 < 1e-20 |
