# N5 降混

`dsp/include/daphne/dsp/downmix.h`、`dsp/src/downmix.cpp`（`daphne::dsp::Downmix`）

解碼後第一個處理區塊：來源超過兩聲道時降為立體聲；單聲道複製到左右；立體聲直接通過（`is_identity`）。

## 公式（以 ITU-R BS.775 為基礎）

令 `t = 0.7071·C + 0.5·LFE`，S 為環繞聲道：

| 部分 | 來源 |
|---|---|
| 中置與環繞各以 0.7071（−3 dB）混入前方左右 | ITU-R BS.775 的降混係數 |
| LFE 以 0.5（−6 dB）混入 | **本專案另外加的**：BS.775 的降混公式不包含 LFE |
| 整體縮放（0.7071 / 0.5 / 0.408248） | **本專案另外加的**：讓單一聲道滿刻度不削波（見下） |

| 版面 | 左聲道（右聲道對稱） |
|---|---|
| 3.0 / 3.1 / 2.1（有中置或 LFE，無環繞） | `0.7071 · (FL + t)` |
| quad / 4.0（一組環繞，無中置） | `0.7071 · (FL + 0.7071·S)` |
| 5.0 / 5.1（一組環繞 + 中置） | `0.5 · (FL + t + 0.7071·S)` |
| 6.1 / 7.1（兩組環繞） | `0.408248 · (FL + t + 0.7071·(S1 + S2))` |
| 無可辨識的聲道 | 前兩個聲道 |

- 公式只取決於「有沒有中置 / LFE」與「環繞組數」（後方、側方、後中置各算一組），缺少的聲道視為 0。
  - LFE 與中置算在同一個判斷裡，所以只有 LFE、沒有中置的 2.1 也用 `0.7071 · (FL + t)`：前方左右同樣降 3 dB。
  - 要符合 BS.775 本身的公式，LFE 的係數應為 0；目前的做法讓 LFE 裡的低頻在立體聲裡保留下來。
- 後中置（BC）以 ×0.7071 平均分到後方一對；沒有後方聲道時由它組成後方一對。
- 前中左右（FLC / FRC）與頂部聲道不混入。
- 整體縮放保證單一聲道滿刻度不會削波；只有所有聲道同相滿刻度的極端情況會超過 1.0（5.1 最多約 +3.3 dB）。處理鏈是 float64，這種峰值會保留到音量與限幅級，不在這裡截斷。

## 聲道角色

- 來自 WAVEFORMATEXTENSIBLE 遮罩；串流順序 = 遮罩位元由低到高。
- 遮罩為 0，或位元數與聲道數不符時，改用聲道數的預設版面：

| 聲道數 | 預設版面 |
|---|---|
| 1 | FC |
| 3 | FL FR FC |
| 4 | FL FR BL BR（quad） |
| 5 | FL FR FC BL BR |
| 6 | FL FR FC LFE BL BR（5.1） |
| 7 | FL FR FC LFE BC SL SR（6.1） |
| 8 | FL FR FC LFE BL BR SL SR（7.1） |
| 其他 | 無 → 前兩個聲道 |

## 實作

- `prepare()` 把上面的規則一次轉成 2 × N 係數矩陣（`coef_left(k)` / `coef_right(k)`）；`process()` 每個 frame 只做兩個內積，沒有分支、沒有逐樣本的角色查找。
- 係數長度跟著聲道數配置，超過 8 聲道的來源不會越界。
- 允許原地處理（`in == out`）：第 i 個 frame 讀完才寫 `out[2i]`、`out[2i+1]`，且 `2i+1 < (i+1)·N`，不會覆蓋尚未讀取的資料；單聲道從尾端往前寫。
- 延遲 0，沒有狀態。
