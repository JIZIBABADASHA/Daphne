# N18 調變器前級（升頻與限幅）

`dsd` 核心在調變器之前的兩級，以及 DSD 檔轉 PCM 後的限幅。程式：`dsp/include/daphne/dsp/limiter.h`、`dsp/src/limiter.cpp`，濾波器沿用 N6 / N7。

## 升頻

- 處理鏈（音量、交叉饋送、EQ）在原取樣率完成後，用**與 PCM 核心同一組濾波器設定**（`filter`：taps、相位、apodize、double-double）升到 705.6 kHz（44.1k 家族）或 768 kHz（48k 家族）：`modulator_input_rate(fs)`。
- 調變器只剩下 705.6 kHz → DSD 時脈的整數倍內插（44.1k 家族：DSD128 是每個樣本 8 bit）。音質由這個濾波器決定，不靠調變器的內插。
- 48k 家族來源也用 44.1k 家族的 DSD 時脈（DSD 標準只有這一族），調變器以三次 Lagrange 內插接上（N19）。

## 調變器前的限幅

1-bit 迴路的穩定輸入有上限（N19 表中的 umax，以參考增益 0.5 換算約 +2.3 … +5.5 dBFS）。超過時調變器會把輸入硬削，響亮母帶升頻後的樣本間峰值就可能碰到這個硬削。所以在調變器前放一個前瞻限幅器：

| 參數 | 值 |
|---|---|
| ceiling | `0.85 × umax / 0.5`（umax 依 osr 與階數，N19） |
| 前瞻 | 2 ms |
| release | 500 ms（低頻內容的 release 太短會產生調變失真；500 ms 讓 50 Hz 的超量失真壓在 −56 dB） |

- ceiling 以下只有 2 ms 的延遲，訊號逐位元不變。
- 0.85 的餘量：迴路在接近 umax 時噪聲與 idle tone 會上升（8 階 DSD64 在 0.9 × umax 時約 −68 dB）。

## DSD 檔轉 PCM 後的限幅（`output.dsd_pcm_limiter`）

DSD → PCM 有 +6.02 dB 參考增益（N3），SACD 允許的峰值會超過 0 dBFS。開啟時（預設）在鏈的最後放一個限幅器，超量時壓低而不削波：

| 參數 | 值 |
|---|---|
| ceiling | 0.999 |
| 前瞻 | 2 ms |
| release | 80 ms |

## 限幅器的做法

- 每個 frame 的峰值（各聲道最大值）超過 ceiling 時，要求增益 `ceiling / peak`。
- 要求值在前瞻視窗內保持（單調佇列做滑動最小值），立即 attack，one-pole release 回到 1。
- 再對視窗做盒形平均，音訊延遲一個視窗。所有值都 ≤ 要求值的平均，會在延遲後的峰值樣本到達時剛好等於要求值，所以沒有任何樣本超過 ceiling，增益是平滑的斜坡而不是階梯。
- 所有聲道共用一個增益，立體聲像不變。
- release 回到 1 − 1e-9 以內時直接設成 1：之後又是延遲後的逐位元相同輸出。
- 盒形平均的累加和每個視窗重新加總一次，避免長時間累積誤差。
- `flush()` 輸出延遲中的尾巴。

## 驗證（`tests/test_modulator.cpp`）

ceiling 0.9、前瞻 2 ms、release 80 ms，48 kHz，440 Hz：0.5 振幅，中間一段 1.4 振幅。

| 測試 | 結果 |
|---|---|
| 延遲 = 96 frames（2 ms） | 通過 |
| 所有輸出 ≤ ceiling | 通過 |
| 超量之前：輸出 = 延遲後的輸入，逐位元相同 | 通過 |
| 超量結束 0.4 s 後：與延遲輸入相差 < 0.6%（release 尾端） | 通過 |
| 2 s 後：再次逐位元相同 | 通過 |
